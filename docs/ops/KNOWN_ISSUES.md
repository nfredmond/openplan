supersedes older blanket full-campaign release requirements below. Historical
partial outcomes remain partial; relevant data, permission, claim and workflow
regressions still block the increment being released. Since October 11, 2026
OpenPlan also runs as a public hosted installation (see
[the cutover record](HOSTED_LIVE_2026-10-11.md)); a defect there affects real
accounts.

work), by the [two-month review](../reviews/2026-10-12-two-month-review/README.md).
Sections below that date record their own review. This is a quality-boundary
register, not a development queue. Scheduling lives only in `docs/ROADMAP.md`.
