# v0.36 portfolio workbook round-trip proof

Date: 2026-08-26
Status: implemented and verified in the development tree

## Outcome

Projects now exposes one active-workspace XLSX download beside the existing
reviewed importer. The `Projects` worksheet mirrors the importer's supported
fields, while `Read me` records the workspace, generation time, mapping,
create-only behavior, geography boundary, formula policy, and reference-only
columns.

The workbook carries project type, status, delivery phase, cost currency, and
cost price year per row. That closes the data-loss seam created by worksheet-wide
defaults without changing the importer's human-control contract: no worksheet
is selected automatically, every row starts as `skip`, matching names still
require confirmation, and import remains create-only.

## Fail-closed boundaries

- The export query is scoped to the helper-selected active workspace and allows
  viewers to download without granting write authority.
- More than 2,000 rows returns `row_limit`; OpenPlan does not generate a partial
  workbook that the importer cannot review.
- A recorded cost without a price year returns `cost_price_year_missing`;
  OpenPlan does not manufacture a year.
- Decimal costs are written as literal strings, avoiding spreadsheet rounding.
  Text beginning with `=`, `+`, `-`, or `@` remains a literal cell, not a formula.
- Place labels can return as source-location text, but neither place identity
  nor boundary geometry is inferred during import. Place provenance is retained
  in reference-only columns.
- Exact OpenPlan headers prefill mappings only after the planner selects the
  worksheet. A changed header falls back to manual mapping.

## Deterministic evidence

Focused Vitest at the implementation checkpoint: 48 tests passed across the
workbook reader/reviewer, workbook builder, tenant-scoped route, importer UI,
and Projects page. The generator test opens its own XLSX, checks formula cells,
then sends the same bytes through `reviewPortfolioWorkbook` and compares the
row-level fields.

The full Vitest run passed 12,601 tests with 77 skips; shuffled seed `364086`
passed the same count. ESLint, the production build, 48 worker suites, 107 live
RLS tests, dependency audit, migration inventory, local Supabase status, product
direction, and first-week discovery/evidence guards also passed. Knip completed
with the repository's existing unused-export inventory and no failing status.

The machine's `/tmp` tmpfs returned `EDQUOT` during the first Vitest, journey-
harness, and worker attempts. Rerunning each with `TMPDIR` on the repository's
disk completed successfully. The first production build also caught a
`NextResponse` body type mismatch; copying the SheetJS bytes into an owned
`Uint8Array` fixed it, and the route test plus production build then passed.

Mutation expectations are explicit: removing workspace scope, the 2,000-row
refusal, the missing-price-year refusal, literal-cell behavior, or the exact-
header check, or the per-row field override must make a focused test fail.
