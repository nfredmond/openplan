# Private retained raster inspection

The recoverable worker already retains selected original product bytes. Extend
that path with a private metadata inspection receipt before artifact preparation.
Reuse the existing GeoTIFF reader, including the rotated vector correction.
No new public module or upload/callback route belongs to this step.

Bind the inspection to the original product receipt, archive, task and observation.
Read only the retained private raster descriptors. Preserve declared dimensions,
CRS, native extents and native cell spacing. These are tag declarations, not
survey accuracy or map-placement approval. Do not derive a public preview or
WGS84 footprint in this stage. Point-cloud decoding remains unassessed.

Keep absent products, unsupported formats, unreadable metadata and successfully
read tags distinct. Preserve a failed or unsupported result with its original
file binding. No failed read can become zero coordinates or assumed metre units.
Completion retains quality, placement, callback and publication as unassessed
or refused, regardless of whether native tags are readable.

Check owned-attempt cancellation and current actor access around inspection.
Retain exact report bytes before its completion receipt. Recovery verifies the
original product plan and report hash rather than parsing a changed file or
silently replacing earlier interpretation with a newer parser. A changed report,
missing original plan, foreign file or stale actor refuses. Existing private
writer and immutable publication helpers handle interruption and aliases.

Source tests challenge readable and absent products, unsupported TIFF, malformed
bytes, changed files during inspection, interrupted report publication, exact
replay, cancellation, access revocation and unsupported claim promotion. Each
changed case needs harmless and targeted fault controls. Useful retained native
output and both interpreter checks follow separately. Default worker wiring,
complete artifact delivery, capacity and planner acceptance remain open.
