## What current CI can and cannot see

The push QA job uses placeholder service configuration. It runs lint, dead-code checks, Vitest, connector tests, dependency audit and build. Its ordinary local RLS gate does not write fixtures unless explicitly enabled. A separate RLS workflow starts a fresh Supabase stack on pushes and pull requests. The upgrade workflow exercises populated predecessor fixtures. The restore workflow runs a scoped full-archive drill with representative records. Scheduled browser smokes use real rendering, but they are not the full twelve-journey/practitioner acceptance campaign.

The main worker CI job covers the AequilibraE directory and modeling scripts with lightweight dependencies and documented skips. It does not discover every ActivitySim, county, OCR or ODM worker suite. The local worker runner discovers more suites and fails when environments are absent. It is not automatically part of `qa:gate`.

The review exposes these specific test boundaries:

- A hash verifier cannot detect mutable fields omitted by its caller. PROV-01 executes the real verifier and route together.
- A mocked Storage signer cannot reveal the installed SDK's normalized request target. SEC-01 composes the guard with that SDK.
- A mocked child process has no descendants or inherited pipes. SCI-02 uses an actual short process tree.
- Connector tests with a mocked finish endpoint cannot detect the app parser's permanent 400. PROV-02 composes both implementations.
- Matching workspace columns cannot validate the relationship between two permitted parents. FIN-02 exercises the actual authenticated RPC.
- A sum invariant does not establish nonnegative shares. FIN-01 checks individual amounts and native constraint behavior.
- A mock honoring every requested page cannot simulate a smaller server cap. FIN-03 supplies short nonterminal pages.
- A table-name-based query mock cannot detect nonexistent filter columns. UI-01 issues the exact query against the schema.
- A directional label is not directional numeric extraction. SCI-03 supplies unequal AB/BA flow and tests the computed number.

The existing focused suites report 46 financial/OWP tests, 126 app provider/approval tests, 25 connector tests, 10 county tests and 14 ActivitySim runtime tests passing. Three artifact/export suites also pass 32 tests. The validation instrument's existing script also completes. The review observations still reproduce. These totals are not added into a whole-repository assurance score.
