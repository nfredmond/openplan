# Private original product candidate

The [design](DESIGN.md) connects the existing original output intake to private
orthomosaic, DSM, DTM and point-cloud files. The stage preserves exact selected
archive-member bytes under current actor access. It records optional absence
without inferring a preset or treating missing data as zero. Default worker
integration, preview rendering, callback and Storage delivery remain open.
