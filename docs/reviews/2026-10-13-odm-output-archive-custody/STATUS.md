# Supplied output archive custody

This M3/M5b prototype retains complete private supplied ZIP bytes and inventories
all regular members. It binds the original engine plan and retained task
observation, freezes limits and source bytes, refuses changed prepared input,
and replays from retained bytes without needing the source location. It grants
no callback, publication, engine-provenance, requested-product or quality claim.
The task observation must report completed, but a supplied report and archive
are not proof of actual useful engine processing.

The first source cohort exercises 15 cases using actual local journals and
synthetic archives. It includes exact byte/inventory receipts, source-less and
copied-root replay, bounds before ZIP parsing/inflation, member names/types,
original observation/plan scope, corruption, interrupted publication aliases,
changed source and deadline refusal. The first harness stops before baseline
on a duplicate unlink anchor. Corrected source controls are running. No source
or native control acceptance is declared yet.

The worker default, hosted settings, migrations, artifact routes and callback
path remain unchanged. Trusted engine download, current runtime authority,
actual processing outputs, requested-deliverable mapping, storage/callback
recovery, complete installation and physical-host recovery remain separate.
The local copied-root case is not cross-host recovery. The private output bytes
are synthetic format placeholders, not validated GeoTIFF or mesh products.
