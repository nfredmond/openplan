# Original terminal delivery, isolated candidate

This candidate retains one terminal callback for an original started admission.
It binds the callback to the saved dispatch, original task observation, exact
body bytes and, for success, the original artifact lease and receipt. Restart
keeps the original callback identity, occurrence time, URLs and expiry. Failed
and canceled observations need no success lease and cannot invent artifacts.

The delivery journal uses separate terminal command, attempt and reply formats.
Current send authority is checked before preparation, after retaining intent,
and after retaining a receiver reply. A completed job permits replay only when
the database retains the exact applied original callback. The active processing
reader remains unchanged.

An ignored reply can survive a later refusal to send. The historical receipt
method validates the original command, observation, lease and all ordered
attempts and replies under original runtime ownership. It reports the receiver
fact without requesting current POST authority. Current access and application
acceptance remain unassessed. It grants no transport or publication permission.

The callback transport accepts an explicit allowance of up to 64 KiB. Its
progress default remains 16 KiB. Invalid child bodies are refused before DNS.
The separate authority transport keeps its 128 KiB private envelope limit and
uses UTF-8 metadata to avoid expanding a valid Unicode callback beyond that
limit. Preparation checks the actual supplied transport allowance before
freezing the terminal command.
