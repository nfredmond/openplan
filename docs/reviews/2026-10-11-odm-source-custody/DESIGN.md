# Retained aerial source bytes, disconnected candidate

The admission journal alone cannot preserve imagery or engine effects. The next
bounded library retains already-complete private local source files before any
engine call. It does not download, extract, authorize processing or register
scientific evidence. Keep the HTTP worker disconnected until the complete
source/engine/result/artifact recovery path passes.

## Local source preparation

Bind the original journal admission, complete parsed request and original receipt
to an explicit private installation/authority context. The trusted dispatcher
supplies that context from existing application records; the worker request has
no actor field. The application currently stores `created_by` on its processing
job before dispatch. Do not invent a current actor, copy authority from a new
retry, or extend the public contract in this candidate. Live authority integration
and source URL renewal remain separate work.

Use the imagery shape in the saved original request. ZIP input has one source;
photo manifest input has one source per original ordered photo. Keep original
metadata and filename, exact raw bytes, sizes and hashes. Verify any declared
photo checksum and byte size. Bind optional ZIP size when declared. Do not treat
an extension or supplied path as proof of complete, valid imagery. Decoding,
extraction and reconstruction acceptance stay separate.

Require explicit private owned source and destination roots without symlinks or
hardlink aliases. Open each source with a no-follow descriptor and verify its
identity, size, timestamps and hash before and after copying. Bound aggregate
bytes and check available disk. Keep ordinary bytes in a stable, safe slot name;
never derive an output path from a photo filename, URL, request ID or job reference.

Before copying, save the complete immutable preparation plan, including each
observed original size/hash and the admission/context identity. Synchronize local
source bytes and plan publication before crossing later custody boundaries.
Copy to fresh private partial files, synchronize and verify exact bytes, then
publish a slot without replacing a different existing object. Preserve partial
files and failed destinations. A resumed pack verifies its original plan and
every completed slot. It may copy a missing slot only from the original declared
bytes with that plan's size/hash. It never calls a URL or adopts a changed source.
No success follows merely from a path existing.

Publish the final portable manifest only after every planned slot verifies.
Original request, admission and authority context stay private. Reopening or
relocating a complete pack verifies all ordinary bytes and returns its original
manifest identity. Unexpected, partial, unavailable and corrupt remain distinct
from complete. This helper does not delete source or partial files, reset a job,
or grant another start permission.

## Reuse and verification

Existing model source custody uses private descriptor traversal, stable file
identity, finite metadata, fresh partial copies, final manifests and directory
synchronization. Reuse those patterns without importing model runtime or NumPy
into an imagery library. The admission journal provides the original immutable
request/receipt. No new product module is needed.

Use real SQLite and private filesystem fixtures. Test full ZIP/photo identity,
declared size/checksum, changed original context/request/source, unsafe paths,
limits, interrupted publication, saved-plan recovery, immutable slots, relocated
verification and unchanged originals. Every test/guard needs a harmless control
and a targeted broken behavior restored in finally. Run serial bounded services.
