## Blind categories remain explicit

Node copied-source loading cannot prove Vite, a Next build, installed provider
behavior or deployment packaging. Vite jsdom imports cannot prove native CLI
protocols, browser navigation, production bundling, accounts or dispatch.
The new pin test observes byte integrity, not truth of historical evidence.
The new Node fixture copies code, so it does not prove connector distribution.

Synthetic budget envelopes cannot prove native error origin, SQLSTATE
reachability, PostgreSQL numeric/JSON transport, complete caller rows, RLS or
snapshot consistency. The centralized boolean classifier remains broad; exact
code/name refinement protects these callers. Removing only the boolean call can
be behaviorally redundant for currently exact known-relation strings, so its
presence alone is not independently demonstrated by those supplied cases.

The unchanged scanner sees regex literals in its existing TypeScript source
scope. It does not prove all possible classifiers, dynamic expressions or runtime
behavior. This delta removes the actual literal and calls the established shared
classifier; it does not change scanner scope to hide it. The ordering guard proves
source filename coverage, not installation, migration execution or release
acceptance. All wider holds remain in force.
