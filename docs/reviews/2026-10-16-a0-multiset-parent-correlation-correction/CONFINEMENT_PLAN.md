# Empty-root confinement plan

This is a source plan, not an observed confinement result. No wrapper has run.

The namespace begins with an empty root and an empty `/usr`. It mounts1218 explicitly pinned Python/interpreter/library files read-only. They derive from the retained M1 CONFIG1237/usr descriptors by source/data projection. The file list contains the Python3.14 standard-library files, interpreter and six fixed ELF dependencies. Seven fixed symlinks preserve the interpreter and loader paths. It does not bind the host root, all of `/usr`, a donor, installed CLI, application tree or old corpus. Host bwrap and systemd-run descriptors are checked outside the namespace and are not mounted inside it.

The25 previously pinned public packet files, three new wrapper sources,38 selected prior inputs and33 fixed data references mount individually and deduplicate by exact filename. Runtime-manifest and artifact-estimate metadata mount as declared config inputs. CONFIG, REQUEST, prepared pins and the future root grant mount separately read-only. Every file has an explicit SHA/length/mode/UID/GID descriptor. Logical source paths remain identical. Retained actual18 and accepted PURE construction inputs remain data, not a new native baseline.

The host authority directory never receives a writable bind. A new `runner-preparation/model-parent-01` directory mounts at the logical PRIVATE location. Read-only directory barriers occupy all real operating-authority/attempt names there. The fixed `PRIVATE/pure-controls` child is absent until unchanged `control_entry.run` creates it. The facade's fake authority exists only below that child. The actual host ROOT authority files cannot be overwritten through this mapping. The new model-parent can contain mount-target placeholders, which are part of the host artifact audit.

The only persistent writable sources are the new model-parent and wrapper attempt. Private home resides in the attempt, and `/tmp` binds its private tmp child. `/proc` and cgroup mount read-only. `/run` and `/var` remain empty. The namespace drops all capabilities and must observe NoNewPrivs1 and Seccomp2. The fixed x86_64 filter denies socket-family operations and io_uring. Network, PID and mount namespace identities must differ from the captured outer identities. No namespace owner equivalence or hostwide confinement claim follows.

The final device operation is precisely `/dev/null` devbind1:3 immediately before clearenv. The inner verifies that null is the only `/dev` entry and is character1:3. No credentials, password file, service paths, host run directory, manager socket, DB socket or warning allowlist mounts. Four fixed write-open probes require EROFS30. Other errno values propagate as failures.

Source/runtime/current-file readbacks and actual mount/resource/status receipts precede the first control import. The receipts preserve raw mountinfo, inherited/nonprivate writable observations, UID/GID maps and samples. Root must audit those actual receipts. The plan cannot prove kernel mount behavior, full ELF closure, exact byte peak, arbitrary filesystem durability, inaccessible alternative host paths, or hard disk quotas. No fallback mount, package install, dependency discovery or automatic second attempt is authorized.
