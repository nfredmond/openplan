Interrupted acknowledgements retain the same request for retry, even after a correction. Browser storage failures preserve the latest reason on screen and require recovery before another operation. Desktop and 390px keyboard journeys, concurrent writes, full QA, shuffled tests and worker checks support this increment.

Apply `20261014000028_engagement_synthesis_approvals.sql` before rebuilding and restarting. No provider key, new worker or paid service is required.
