# Advance original aerial draft commands without repeating uncertain effects

Compose the owned admission runtime and local preparation with the original engine
command journal. A supplied permission adapter evaluates the original context,
engine plan and exact next command before a first issue. Its exact `True` result
permits that controlled invocation. This interface does not attest the adapter,
verify actual membership or implement a deployed application authority seam.

Advance initialization and original image slots in journal order. Each durable
intent precedes transport; each checked exact reply precedes the next command.
An unresolved prior intent holds all later commands, even when the caller's gate
returns true. Existing intents never receive a second issue. A complete draft
still leaves commit unissued. Missing task info, callback delivery or a successful
upload response cannot infer custody or retry permission.

Open the original retained image through the existing private reader. Recheck
size/hash at the transport boundary, use the exact planned multipart filename
and pass detached metadata to adapters. Validate the exact response and save it
through the existing effect journal. A late or failed transport leaves its
original intent unresolved. The transport adapter owns actual request cancellation;
a returned timeout alone does not establish that external work stopped.

Use real owned runtime and retained inputs in tests, harmless/targeted controls
for every changed guard, and only fresh owned cached engines for native init/upload
checks. Exercise acknowledgment loss without reissue. No processing commit,
reconstruction, public worker contract, deployed default, schema or hosted change.
Full worker recovery and live authority remain open. Main merges stay held until
the coordinator's dated clearance after handoff, separate Opus and blockers.
