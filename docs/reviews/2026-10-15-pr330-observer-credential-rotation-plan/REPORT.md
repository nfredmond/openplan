## Recovery retains data and acknowledges rollback limits

Preserve a private generation-to-installation/backup/journal index, required reader revision, cipher format, record references, digest provenance, retention reason and credential revocation status. Existing secret copies remain in their protected recovery custody; the public index contains names/hashes only. Recover old records in an isolated compatible installation without making revoked provider credentials active again.

Do not bulk re-encrypt retained rows, envelopes, grants or journals. Saving a workspace key changes its ciphertext fingerprint; older queued translation requests can then refuse. Immutable API revisions and synthesis authorization digests also require their exact bytes. A provider key revoked after preparation can make an otherwise decryptable request unusable. Preserve that refusal, resolve uncertain dispatch state and obtain a new approval where needed. Do not rewrite old approvals to refer to the replacement credential.

Once B writes exist, rollback to an A-only binary/configuration loses readability. Keep PR328-capable readers with B/A or A/B, or roll forward. Before provider revocation, an approved compatible prior configuration may restore service, but it reuses the affected credential. After Mapbox deletion, the deleted token cannot be restored. Census revocation reversal is not established. Supabase hosted legacy deactivation can be reversible, but re-enabling restores the affected credential's access. A local signing-secret rollback likewise reaccepts old tokens. These are security regressions requiring an explicit decision, not automatic recovery. Signed URLs, expired JWTs and already accepted provider charges cannot be repaired by changing application environment variables.

Receipt custody must retain both exact encodings: working insertion-order JSON and durable sorted-key JSON have equal parsed content but different byte hashes. Keep the original false byte-equality observation. Do not canonicalize originals or substitute one representation's hash for the other's.
