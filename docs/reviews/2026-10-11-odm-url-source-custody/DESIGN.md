# Retain complete original URL source bytes before preparation

Continue M3 and M5b.2 above the supervised draft HTTP candidate. Freeze original
admission, request, started context, supplied application job, installation and
target before writing source objects or calling a fetcher. The original actor
comes from the supplied application projection. Live authority stays unassessed.
This candidate does not add a database query, route or deployed worker contract.

Use a private source root outside the runtime root, preserving the preparation
overlap guard. Seal its installation and target. Each request has one immutable
plan and one writer lock. Bound the whole source set, validate declared sizes and
hashes, and check deadline and explicit cancellation before byte writes. A supplied
fetcher must honor those controls during blocking work; actual supervised URL
transport requires a separate proof. Do not wire the legacy fetcher as a default.

Write each attempt to a new exclusive private object. Flush and synchronize its
bytes and directory before publishing an immutable complete slot receipt with
size, hash, original plan hash and relative object path. Do not infer completion
from an existing filename. Leave interrupted or orphan objects unaccepted for
inspection. Freeze the object budget in the plan. Per-request attempt storage is
bounded at twice the source byte limit and twice the original slot count, including
orphan objects. Exhausted limits hold without deleting evidence. Global retention,
metadata overhead and complete installation capacity still need operational proof.
A missing receipt can start another byte attempt before preparation;
a retained complete receipt prevents refetch or replacement, even if its URL
changes or expires. Missing or corrupt completed bytes refuse rather than fetch.

Validate all completed slots before publishing the source-set manifest. Replays
and restored copies verify retained bytes without transport. Compose the returned
relative source paths with actual existing preparation so its task and engine
plan use those exact retained bytes. Do not issue an engine command. A separate
source root needs a separate stopped-root snapshot; a runtime-only package cannot
establish recovery of interrupted URL intake.

Prove bounded writes, exact receipts and metadata, changed actor/target/request,
missing/corrupt completed data, partial attempts, cancellation/deadline and
relocated-root replay. Every new test or guard needs harmless and targeted broken
controls. Run serially under owned resource caps, preserve failed trials and stop
only owned children. Complete worker, live authority, public-network, scientific
and browser acceptance remain open. Main merges remain held.
