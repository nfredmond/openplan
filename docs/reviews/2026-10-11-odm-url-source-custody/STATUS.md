# Keep original aerial URL sources through interruption

This isolated M3 and M5b.2 candidate adds `url_source_custody.py`. It retains
complete private source bytes before existing owned preparation. Original
admission, request, actor, supplied application job, installation, target and
ordered source metadata stay bound to the first immutable plan. Deployed
defaults, application routes, public schemas and migrations stay unchanged.
Main merges remain held for the relaunch coordinator's dated lift.

The caller supplies a byte fetcher and the application projection. Neither is
live authority. A separate supervised network adapter still needs implementation
and proof. This candidate sends no engine command, processing commit or callback.

## Durable bytes and bounded attempts

The private source root has its own installation and target seal and must not
overlap the runtime root. Intake requires the actual runtime lifetime owner and
an original started admission. It saves the immutable plan before fetching or
writing source bytes. Changed request, actor, target or budget refuses.

Each attempt creates a new exclusive private object. Writes check cancellation,
deadline and the remaining whole-job byte limit before storing excess bytes.
Completion synchronizes the data and directory, independently reads and hashes
the object, checks original declarations and publishes an immutable slot receipt.
An orphan filename never establishes completion. Interrupted objects remain
unaccepted. Attempt objects and their retained bytes have separate original
limits, including empty or partial failures. Exhaustion holds without deleting
evidence. Global retention and metadata overhead remain unproved.

A complete slot receipt prevents another fetch. Replays verify the actual saved
bytes. Missing or corrupt completed data refuses rather than downloading a changed
URL. All slots must verify before the immutable source-set manifest publishes.
Existing preparation consumes the returned exact local paths. Source completion
does not grant engine transport permission.
