Five tests for the contract

Self-service

Install, operate, recover, and upgrade without founder help or paid infrastructure.

One product

Projects and plans retain context across every module transition.

Any place

US-wide today, with country-specific systems kept behind adapters.

Outcomes

Only reached passes. Completed-plus-partly fails.

Defensible handoff

Source, tier, limits, responsible human, and frozen evidence travel with the result.

A v1 program, not a six-release countdown

There is no calendar deadline and no maximum number of pre-v1 releases. Each lane ends in evidence that can fail; national averages never conceal a failing place or practice.

Now

Make it one product and establish honest baselines

Carry project and plan context through real workflows; fix partly reached journeys; publish the first observation-quality and nationwide validation protocol before opening new holdouts.

Proof: four planning outcomes reach their intended result, and validation distinguishes model error from count uncertainty.
A

Validate the dual travel model nationwide

Fix distribution, external travel, network loading, unloaded links, coefficients, transit, and observation error. Preserve the two methods separately and run resumable jobs for as long as accuracy requires.

Proof: preregistered untouched holdouts pass by state, use, and geographic archetype; no national average rescues a failing stratum.
B

Make every state work in substance

Maintain source, law, agency, geography, limitation, journey, and artifact cells for all states and DC, plus explicit territory assessment.

Proof: every applicable underlying cell is proven; California separately passes the gold-standard suite.
C

Complete every planner's core work

Deepen and connect transportation, land use, environmental, engagement, programming, delivery, records, and development-review practice. Add a module only when a fresh review proves no coherent existing home.

Proof: every practice-by-organization journey produces a usable, approved artifact.
D

Complete interoperability and evidence custody

Round-trip work through agency GIS, workbooks, documents, public packets, reports, and records while retaining provenance and limitations.

Proof: independent tools reopen and reuse the artifacts without reconstructing the evidence.
E

Prove teams, operations, and human control

Complete roles, exact-artifact approval, My Work, accessibility, long-job recovery, backup, restore, upgrade, and free self-hosting.

Proof: analysts, approvers, viewers, operators, and public users complete governed journeys through failure and recovery.
F

Add agentic control after the base workflows are real

Build the deferred MCP server as a read-to-propose control surface over complete workflows. OpenPlan remains fully functional without it and consequential acts remain human-approved.

Proof: the agent cannot impersonate, invent, promote a claim, or bypass the exact executed-payload approval.
v1

Run the national proof campaign

Every required cell is proven on one candidate commit, an independent person operates the system unaided, and fresh adversarial reviews find no unresolved core omission.

Only then: tag v1.0.0. A date, effort estimate, or attractive aggregate cannot substitute for the contract.
