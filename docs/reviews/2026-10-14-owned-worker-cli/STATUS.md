# Explicit command for the original worker service

October 14, 2026. Isolated unmerged candidate after owned-service93104a0bd.

The command reads explicit private files for non-secret operator configuration,
credential roles and preset options. It constructs the existing sealed Bundle and
owned Service. It does not change main.py, the container command, hosted settings
or the legacy worker. Operators must select this command explicitly.

Input files must be absolute, private, single-link regular files in a private
owned parent. Symlink aliases refuse. Files are bounded at 64 KiB before reading,
checked for complete canonical JSON, and never printed. Credential maps must name
the original application, engine and callback references exactly. Each supported
preset has explicit bounded options; missing request presets use the operator's
balanced entry. Adapter snapshots and returned copies preserve original values.

The command installs SIGINT and SIGTERM handlers, stops the owned service and
restores prior handlers even after close failure. Outer failures return2 and
print a fixed diagnostic without command values, file data or provider errors.
Normal lifecycle uses the existing Service's lifetime owner and connection drain.

Both Python 3.14 and 3.11 pass four 32-case cohorts and 41 intended faults. Harmless
changes survive; faulted behavior fails at its named diagnostic; source and tests
restore in finally. The oracle and source census are challenged separately.
The actual child fixture starts the real Service, admits and replays one request,
retains the receipt, answers process-only health and stops on SIGTERM.

Historical failures remain retained privately. The first runner has a quoting
syntax error and makes no test claim. An earlier size fixture grew when its
implementation limit changed, and an argument fixture failed at required options
before examining unknown values. Those faults survived. Fixed-size input and a
complete argument list now exercise the intended boundaries. The size test also
refuses reading oversized contents, and each preset differs from the others.

This does not run an engine, full application callbacks/Storage, existing-root
adoption, public TLS, hosted activation, measured capacity or an independent
installation. The child accepts work while its scheduler is deliberately idle;
it does not prove processing that work. Related suites and frozen static review
remain separate evidence. See [operator instructions](INSTALLATION.md).

The frozen review finds a child startup race: the immediate first scheduler pass
could see the admission before its long polling delay. An actual restored cohort
confirms a started entry. The final fixture observes the real first empty pass
through an inherited pipe before POST and checks the saved entry remains accepted
with no start context. No scheduler behavior is replaced. Direct --help separately
exercises the file entry point. The phase-corruption fault fails that assertion.

An earlier broader Python 3.11 run returns2 after SIGTERM. Its fixed outer message
preserves no inner exception, so the exact historical cause remains unknown. The
CLI now treats InterruptedError as graceful only after its installed handler
records an operator stop. Unrequested interruptions and other errors still fail.
Explicit fault controls establish that behavior. Both final interpreter runs pass
197 related cases each. Frozen snapshot02 finds no further concrete defect,
with static limits in [the review](INDEPENDENT_REVIEW.md).
