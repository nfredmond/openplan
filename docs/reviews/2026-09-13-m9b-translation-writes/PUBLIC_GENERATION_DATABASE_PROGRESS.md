## Implemented candidate

`public-generation-queue-candidate.sql` extends the existing generation request, field, reservation and output tables. An explicit authority kind separates staff requests with actual actors from public requests with no invented staff actor. An immutable private mapping binds the public request to its share-token hash, approved original item and parent, campaign/workspace, exact title/body snapshot and locale. Requests for the same current public source deduplicate before credential preparation is required by SQL. Staff readers/catalogs exclude the public request shape.

The existing worker packet, encrypted credential format and output-retention RPC remain reusable. Claim, dispatch and worker-status checks now dispatch through the appropriate authority guard. The public allowance is 30 per 300 seconds, separate from staff's 20. Reservations and dispatch events both count under the workspace public-budget lock. Recording a dispatch and changing its state are one transaction; failed recording cannot authorize a provider call. The conservative event records authorization, not proof of actual provider receipt. The public read DTO exposes only request identity, language, state and completed words, after rechecking current public authority/source. Provider metadata, source packets and credentials remain private.

This is an uninstalled application candidate. Do not claim the old anonymous HTTP path is fixed: it still calls the provider directly and meters afterward. Worker/HTTP/browser joins, supported-language validation through the shared adapter, pre-credential replay lookup and deliberate retry-after-failure behavior are not complete.
