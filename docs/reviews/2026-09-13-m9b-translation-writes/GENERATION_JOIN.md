# Translation generation implementation join

Source inspection on September 13, 2026, following 6b65d82e. This is an implementation decision for unfinished M9b work, not a generation completion claim.

The existing campaign translations route still calls translateEngagementText synchronously and publishes its output in that request. It has separate suggest and publish_machine actions. The helper retains only translated text, model and a caveat in its returned result; it does not expose an immutable attempt identity, provider receipt or retained completion. Generation, publication, retry and usage accounting therefore still need their durable join.

Reuse the existing local API worker's journal/attempt pattern instead of building another runtime or treating generation like a deterministic export. See openplan/src/lib/assistant/provider-api-worker.ts and openplan/scripts/workers/provider-api.ts. The worker holds the shared connector OS lock, binds a private journal to a database target and immutable attempt, persists completed output before delivery, and verifies the acknowledgement. A running journal after interruption never invokes the model again. The dispatch reservation and actor/connection recheck are in openplan/supabase/migrations/20261012000002_assistant_api_turns.sql. These are concrete reuse points, not proof that translations currently use them.

The engagement report worker in openplan/src/lib/engagement/review-export-worker.ts has reusable artifact custody ideas, but its rebuild-on-missing-cache behavior is unsuitable for a possibly billable model attempt. Do not copy that retry policy into translation generation. The retained generation request must bind exact source words, language, selected fields, actor/campaign/workspace, provider configuration and explicit attempt identity. Preserve completed per-field results through interruptions. Delivery and publication must not trigger another generation, and publishing must still check current source and translation versions through the transactional command.

Keep staff and public attempt allowances separate. Reserve actual dispatches durably; missing credentials are unavailable, not a successful generation or a billable attempt. Public cache hits need retained completion provenance, with legacy unknown provenance left unknown. Do not regenerate old cached words automatically to fill missing evidence. Finish private access/recovery browser checks, generation/worker/producer conversion and release checks recorded in NEXT.md. The command's ordinary authenticated grant remains revoked until all producers have a supported path. No real paid model call is authorized by this note.
