# Current access now precedes each original draft command

This candidate follows capacity PR #261 at `088a43a7e`. It composes the saved
application original with the private current-access reader. Every pending
init or upload requires current access and a separate engine-attestation adapter.
Saved custody remains unassessed and does not grant engine permission.
Processing commit and the default worker stay unchanged.

The adapter checks the complete engine plan, exact operation and command,
configured engine and saved admission/context before querying current access.
Project scope remains bound through the saved original request and eight-field
application record. A false access result stops before engine attestation.

callback and actual shared deadline. The owner and deadline are checked again
after it returns. The opt-in selection and deadline pass through original
dispatch, URL and draft layers. Legacy supplied adapters keep their call shape.
