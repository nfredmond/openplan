# Prepare original aerial inputs inside the owned admission runtime

Compose the actual durable admission runtime with the existing retained-source,
ZIP derivation and original engine-plan libraries. A caller supplies already
complete private local inputs and an original application-job projection. The
projection includes the recorded actor, request, workspace, mission, preset and
imagery type. Missing actors or mismatched scope refuse before source access.
The worker bearer token and request external reference do not identify the actor.

The application route records `created_by` before dispatch, but the public
contracts omit that actor. This candidate accepts an explicit supplied projection;
it does not add an application endpoint, attest the projection or verify current
membership. Original context and all authority/custody grades remain unassessed.
A future trusted adapter must collect and verify that projection. No deployed
contract or configuration changes.

An owned, durably started admission precedes preparation. Freeze the original
request/admission/start context, application record, installation, target, limits,
source mapping, engine identity/settings and one task UUID before source retention.
Recover that UUID and identity from the saved preparation plan. Source-root
locations may change after stopped-root restoration; original relative mappings
and actual byte identities may not. Fixed retained/derived/engine roots live below
the owned runtime, with a distinct per-request directory.

The callable pipeline prepares exact source bytes and the original engine plan.
It does not issue init/upload/commit commands or send callbacks. Its local
`prepared` state leaves the original start held. An explicit local resume method
may verify and complete preparation for that same original start without granting
external transport permission or allowing later queued jobs to run.

Exercise real runtime ownership/start, local source custody, both input shapes,
interrupted source copying, saved UUID replay and relocation. Mutate every new
guard/test with harmless and targeted controls. Preserve failed trials, completed
source records and original admissions. Main merges remain held until the
coordinator records a dated lift after handoff, separate Opus review and blockers.
