# Next M9b generation boundary

September 30, 2026. Read-only investigation while release CI runs. No new generation behavior is implemented or accepted.

The active roadmap selects optional complete resumable generation after the reviewed synthesis links and exports. Keep Analysis, retained source snapshots, staff review revisions and separate exact approval. Do not revive the retired generator or add a separate engagement module.

## Reuse and avoid

`src/lib/engagement/synthesis-sources-server.ts` verifies exact saved snapshot bytes, campaign/workspace identity, selected counts, source references and historical definitions. New generation must begin with this server-verified snapshot. Preserve selection exclusions, unavailable historical context and sessions without selected answers. Do not use a current live campaign query to stand in for the immutable source.

`synthesis-review.ts` computes exact complete group membership, explicitly unassigned and overlapping sources. Its initial content is a staff draft derived from historical categories, with sentiment not assessed. Generated proposals need separate machine authorship, original output receipts and explicit staff acceptance into a new retained review version. Do not impersonate staff or overwrite older drafts or approvals.

`translation-generation-worker.ts` already uses a locked private journal, reserved attempts, lease/status checks, saved completion before delivery, and interruption without automatic provider replay. Its queue checks saved requests before preparing credentials. Reuse these execution and recovery conventions, while keeping synthesis jobs and original generation receipts distinct from translation fields.

`translation-generation.ts` is an Anthropic-specific adapter for one translation field. `provider-api-generation.ts` supports retained compatible-API revisions, including a no-key configuration, but its packet and output contract are specifically project questions. Reuse credential and transport mechanisms without pretending those business schemas accept synthesis. Inspect CLI connector task dispatch and saved model configuration before deciding the provider integration. Manual preparation and review remain free and usable without a model.

`ai-synthesis.ts` retains the old 300-item and 600-character caps. Its deterministic fallback assigns neutral sentiment and retains at most eight member references per group. The public write route is retired with HTTP410. This code is historical compatibility, not the foundation for complete new generation.

## Required implementation evidence

The generation plan must account for every selected comment, reply and answer, full text and historical question/category meaning. Divide work by explicit source ranges or complete records with stable identifiers and exact hashes. Large records and long context require continuation with complete reassembly, not clipping. A request beyond configured resources remains incomplete or unavailable with its full source retained. Completing provider calls alone cannot establish complete analysis.

Retain each dispatch, exact input, selected backend/model revision, output, finish reason, usage and source coverage. Preserve minority/conflicting input and require every proposed group to identify its exact source membership. Missing citations, unknown sources, duplicate or absent segments, incomplete provider output and a failed save must not produce a completed review. Coverage verifies source accounting, not semantic correctness or representativeness.

Cancellation, access revocation, lost acknowledgement, worker death before or after provider return, lease expiry and saved-output redelivery need native and worker controls. An uncertain paid request must not be silently issued again. Staff choose whether to start a new attempt. No live paid calls are authorized by synthetic engineering tests.

Acceptance includes more than300 contributions, long and multilingual sources, survey-only and mixed input, retained historical choices, unknown definitions, empty retained selection, overlapping sources, changed live input, stale review corrections and explicit staff acceptance. Each changed guard requires a harmless control and a targeted failure. Browser evidence must use actual navigation, keyboard, desktop/390px, interruption recovery and private access. Completed synthetic output proves custody and recovery, not live model usefulness.

This investigation does not complete M9b, change capability ratings, remove agency authority boundaries or reduce any V1 obligation.
