# Explicit original worker assembly draft, October 14

The draft constructs the existing original runtime from explicit operator
settings. It joins source custody, authorized drafts and one commit, running
progress, task observations, output retention, artifact access, terminal delivery
and old-outcome recovery. Credential resolvers run at transport time. The factory
starts no server, polling loop or engine and leaves the default worker unchanged.

The changed configuration adds separate source and callback address policies.
Their networks and ports are explicit; callback redirects remain forbidden.
Existing unsealed roots still require separate adoption. Unsupported native
profiles and invalid adapter bounds refuse before publishing the operator seal.

## Draft checks and review

Four 33-case assembly cohorts and 33 intended faults pass on each of Python 3.14
and Python 3.11. Four 41-case configuration cohorts and 41 faults pass on each.
The updated observation campaign passes four 19-case cohorts and 23 faults,
including an actual stalled task GET that closes after cancellation. Historical
failed timing and diagnostic campaigns remain retained separately. Both interpreters pass 134 related cases. The 19 nested document/direction/release-order checks pass from the actual
application directory.

The assembly cancellation seam also uses an actual supervised observer child
and local Unix daemon socket. It observes cancellation after the GET begins,
then stops and reaps that child. Removing cancellation reaches the read deadline
instead of the required interruption. The fixture daemon is not Docker and this
does not establish native engine behavior or processing quality.

Frozen independent review finds cancellation, seal ordering, direct-download,
transport-setting, authorization-role and persistent-bound gaps. The corrections
forward cancellation into task reads and native attestation, validate pure
assembly before sealing, wrap direct access/download calls, pin active transports
and authorization roles, and compare persistent settings before operation.
Early refusal uses a fixed socket-write timeout even when a mutable timeout is
invalid. Snapshot 05 identifies no further concrete defect in that correction.
The review is static and does not execute these campaigns.

The observation interruption fixture requires a real stalled local task GET to
close after cancellation. Its first broken variant reached the fixture deadline,
so that failed campaign stays historical. The revised fixture releases the
server before the read deadline when cancellation is ignored, isolating the
intended assertion. Ordinary local files, supplied facts and source guards do not
establish a running native installation or complete application receiver.
