# State injury-crash data sources

Research date: November 1, 2026. Scope: whether each state and DC publishes crash-level data with injury severity that OpenPlan can read for free, query by area, and reuse publicly. Author: OpenPlan research lane, with four parallel research agents for the regional sweeps. Sources are state DOT, state police and state open-data pages, the ArcGIS REST services those agencies publish, their data dictionaries, and their terms pages. Third-party mirrors were not counted. The machine-readable registry beside this note, [STATE_INJURY_CRASH_SOURCES_2026-11-01.json](STATE_INJURY_CRASH_SOURCES_2026-11-01.json), carries the same rows with full service URLs.

## Four jurisdictions besides California are usable now

Three states and DC publish open, area-queryable crash points with injury severity and a public-reuse statement: Iowa, Ohio, Oregon and the District of Columbia. With California's CCRS, five jurisdictions qualify. Twenty-seven more states publish crash-level injury data with at least one limit, most often no stated reuse license. Fifteen states are not usable, and four are unknown.

| Verdict | Count | Jurisdictions |
|---|---|---|
| Usable | 5 | CA (registered before this review), DC, IA, OH, OR |
| Usable with limits | 27 | AK, AR, CO, CT, DE, FL, HI, ID, IL, KS, ME, MA, MS, MO, MT, NJ, NY, NC, OK, PA, SD, TN, TX, UT, VT, VA, WI |
| Not usable | 15 | AL, AZ, GA, IN, KY, LA, MD, MI, MN, NE, NV, NM, RI, SC, WY |
| Unknown | 4 | NH, ND, WA, WV |

The November 1 direction review's falsifier ("if fewer than three states besides California publish open injury data, the gap becomes a visible per-state v1 blocker") is not triggered: three states qualify, plus DC. The margin is one state. For every state outside the usable row, the injury-data gap is a per-state limit, and the known-issues register records it.

Nevada, the first proven cell's second state, does not qualify. NDOT's two open crash services (`CrashData_OpenData` and `CrashData_OpenData_2019_2023` on gis.dot.nv.gov) answered "Service ... not started" on November 1, and the TrafficSafety service folder lists no crash service. NDOT's current route is a crash data request form, published as an NDOT ArcGIS Survey123 form. A search summary of NDOT's older request forms reports that they cite 23 USC 409 and bill research time at $35.00 per hour, with government projects exempt; the forms themselves returned 403 to direct checks, so those terms are unverified. Nevada Safety work stays fatal-only (FARS) until NDOT republishes an open layer.

## Verdict rules

- **Usable:** crash-level rows; a severity field the publisher documents or codes; coordinates or a geometry; free with no key, or a free key without approval; queryable by area; and a public-reuse statement, an open license, or a public-information statement.
- **Usable with limits:** as above but missing one element. The most common gap is no stated license. Others are county-only location, no serious-injury split, stale years, or bulk files without an area API.
- **Not usable:** aggregate only, request or approved registration, terms that forbid redistribution of derived results, or a fee.
- **Unknown:** the check could not be completed. Unknown never means absent.

## Implementation choice

OpenPlan implements Oregon first (`odot-or`). It is the usable state with the closest tie to existing work: Oregon is a configured exemplar in the jurisdiction readiness registry, and its safety claim said "an Oregon all-severity crash source is not configured." The layer carries the source's own KABCO letter, and ODOT's 2024 Motor Vehicle Traffic Crash Analysis and Code Manual defines each letter (Injury Severity, pages 185-186).

Three findings from reading Oregon's layer changed the adapter:

1. **Unlocatable crashes sit at default points.** The code manual says the Unlocatable Flag places a crash "at default locations within the municipal jurisdiction." On November 1, 4,203 of 273,810 crashes carried it. The adapter excludes them from area queries, because a default point is not a location.
2. **The "present" flags are not involvement flags.** No crash with `Ped_Pres_Flg = '1'` has a pedestrian participant (4,824 crashes have one; 2,960 carry the flag; none carry both). Pedalcyclists show the same split (3,225; 247; 0). The adapter uses the manual's documented participant counts, `TOT_PED_CNT` and `TOT_PEDCYCL_CNT`. It does not read the undocumented motorcycle flag.
3. **No open license is named.** The OTSDE item states "There are no access constraints" and invites users to "download data to perform your own analyses." ODOT's Crash Data Disclaimers (April 14, 2026) anticipate re-release by customers. The adapter's attribution says no open license is named.

The adapter is read-only. `safety_crashes.source_id` admits only `ccrs-ca` and `fars-national`, so an Oregon live read and corridor run get KABCO severity, and an Oregon Safety acquisition still stores fatal-only FARS until a migration widens that constraint.

## Iowa, Ohio and DC: second round

A second lane implemented the other three usable jurisdictions as `iowadot-ia`, `odot-oh` and `ddot-dc`, in the Oregon adapter's design. Each was re-checked on the live service on November 1, 2026 before any code was written: layer metadata, field names and coded domains, record counts, years, an envelope query in EPSG:4326, page limits, where unlocated crashes go, and the license text. All three passed. Like `odot-or`, all three are read-only until a migration widens `safety_crashes.source_id`.

**Iowa** ([Crash_Data FeatureServer layer 0](https://gis.iowadot.gov/agshost/rest/services/Traffic_Safety/Crash_Data/FeatureServer/0), [item](https://www.arcgis.com/home/item.html?id=7a1f786d55a2439a9bfa8f7a527936e8), [data dictionary](https://cloud.iowadot.gov/gis/data/metadata/crash/Crash_Data.xlsx)). The layer held 639,173 crashes dated January 1, 2015 to October 29, 2026, with a page limit of 2,000. The item states "This work is licensed under a Creative Commons Attribution 4.0 International License," with Iowa DOT's [GIS Data Terms of Use](https://iowadot.gov/policies-statements/terms-use) (effective June 19, 2026) as additional terms; those terms disclaim warranties and ask users to indemnify Iowa DOT. Four findings shaped the adapter:

1. `CSEV` code 2 is "Major Injury." Iowa DOT's own person layer names the same class "Suspected Serious Injury Crash," so it maps to serious injury.
2. Code 4, "Possible/Unknown" (101,602 crashes), holds both possible injuries and unknown injuries. The adapter uses the documented `POSSINJURY` count: 84,021 such crashes have a possible injury and are injury crashes; the other 17,581 stay unknown.
3. Unlocated crashes sit at one default point in Nebraska (UTM 15N 190000, 4460000), which holds 1,309 crashes. The adapter excludes that point by its coordinates.
4. The crash layer has no pedestrian or bicyclist field. Iowa DOT's person layer (also CC BY 4.0) has a non-motorist type, and every 2024 non-motorist person row sits on its crash's point (737 of 737 crashes), so the adapter reads it by the same envelope.

Iowa DOT's web application firewall answered a block page to one WHERE shape (`IS NULL OR ... <>`). The adapter's queries avoid it; a block page reads as unavailable, never as zero crashes.

**Ohio** ([TIMS Safety services](https://tims.dot.state.oh.us/ags/rest/services/Safety), [2025 layer metadata](https://tims.dot.state.oh.us/ags/rest/services/Safety/2025_Crash_Locations/MapServer/0/metadata)). One service per year, 2021 to 2025 (2024: 251,091 crashes; 2025: 264,530). The metadata states the data "is deemed to be public information" and names no license. Severity is ODOT's five-level `CRASH_SEVERITY_TXT`, identical across the years checked. Every row has coordinates; the metadata does not say whether crashes ODOT could not locate are left out. The layer has no day of month, no casualty counts, no lighting and no weather, so those stay null. Pedestrian and bicyclist involvement come from the crash type alone, which is a floor.

**DC** ([Crashes in DC, MapServer layer 24](https://maps2.dcgis.dc.gov/dcgis/rest/services/DCGIS_DATA/Public_Safety_WebMercator/MapServer/24), [Open Data DC item](https://opendata.dc.gov/datasets/70392a096a8e431381f1f692aaa06afd), [DDOT crash data page](https://ddotwiki.atlassian.net/wiki/spaces/GIS0225/pages/2053603429/Crash+Data), updated March 10, 2025). The layer held 356,668 crashes with a page limit of 1,000, under "a Creative Commons Attribution 4.0 International License." DDOT states that a crash with missing or incomplete location data "is unable to be published within this dataset." There is no severity field. The adapter derives one from DDOT's outcome counts: any fatal count is fatal, any major injury is serious injury, any minor injury is injury, all counts zero is property damage only, and anything else (an unknown injury, an unreadable count) stays unknown. DDOT's minor class includes pain and discomfort, so B and C are not separated. `REPORTDATE` is the date the crash was reported to MPD, so DC years are report years and no crash date is claimed. The "other" outcome columns are null on 253,552 crashes reported before June 2024.

Two findings apply to every ArcGIS layer. Some servers upper-case statistic names (Iowa and DC return `N` for `n`), and the count and feature queries can disagree by a point on the envelope's edge (DDOT counted 30 crashes in the test box and returned 29). The shared reading loop handles both.

## Limits of this review

- The regional sweeps were run by research agents. The lane re-checked Nevada and Oregon directly, and re-read the license text and record counts for Iowa, Ohio and DC on November 1. Other rows rest on the agents' recorded queries and quotes.
- Several sites blocked or failed automated requests: dot.nh.gov (403), the Washington State Patrol Collision Analysis Tool (expired certificate, then 503), the KDOT terms page (403), TxDOT CRIS Query (503) and the WVDOT crash page (404). Those rows say so.
- "Usable with limits" is not a judgment that a state's terms permit OpenPlan's use. A state that names no license may still object to redistribution. Read each source's terms again before writing its adapter.
- Layers change. Utah's feed stopped on August 5, 2025; Florida's stopped in 2022; Nevada's services stopped before this check. A registered adapter fails as unavailable, not as zero crashes, when its layer stops.
