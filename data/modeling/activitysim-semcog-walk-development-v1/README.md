# SEMCOG walk constants, development transfer

This package transfers 27 individual home-based tour WALK constants from the
ActivitySim 1.5.1 `production_semcog` example into the otherwise unchanged
`prototype_mtc` coefficient file. The named set is
`semcog2015-walk-asc-development-v1`.

This package is not an accepted component and is not connected to default
bundle construction. Use only the explicit research command. The current
accepted-component registry remains unchanged.

`source/` retains the version-tagged donor specification, template, coefficients,
source hashes and BSD license. `overlay/coefficient-set.json` records every
baseline/donor value and the resulting file hash. `overlay/` contains the
research-only coefficient file. The package-level BSD license also covers that
derived file. The source calibration description does not establish that this
vector transfers to a different alternative set, geography or year.

[Preregistration](../../../docs/modeling/activitysim-coefficients-2026-10-23/PREREGISTRATION.md)
freezes the experiment and its observation requirement. No reduced simulated
walk share establishes accuracy. No AequilibraE comparison enters the decision.
